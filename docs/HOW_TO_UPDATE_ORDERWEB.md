# How to update OrderWeb (1-page guide)

Admin URL: **`/owadmin`** — bookmark it. Do not put it in the public website menu.

## Sign in

1. Open `/owadmin`
2. Email + password  
3. Forgot password? Use the link on the login screen (needs email configured)

## Safe update flow

1. Open **Pages** → choose the page  
2. Edit one section at a time (heading, text, image URL, button)  
3. **Save draft**  
4. **Preview** — check the site looks right  
5. **Publish** — only then does the public site change  
6. Mistake? **Revert** to last published  

### About page tip

About is split into **Part 1–5** (Our story → Problem → Difference → More than POS → Mission). Use the page map chips to jump; open only the part you need.

**Replace the story picture:** Part 1 → **Replace picture** → choose a JPG/PNG → Save draft → Preview → Publish. Use default picture restores the built-in image.  

## Images

1. **Media** → upload  
2. Copy the image URL  
3. Paste into the page’s image field  
4. Add alt text when you can  

Leave an image field blank to keep the built-in default (site won’t go blank).

## Pricing / contact

- **Pricing** is Part 1–6 (Hero → Value cards → Compare → Plan → Calculator → Add-ons)
- Part 1 / Part 6: **Replace picture** to swap images
- Part 4 **Price** also feeds the savings calculator
- **Contact** is Part 1–3 (Hero + picture → Details → Form labels)
- **Restaurant POS** is Part 1–5 (Hero + picture → Tour → Payments → Feature map → Bottom button)
- **Website** is Part 1–5 (Hero + picture → Promise strip → Demo websites → Roadmap → Bottom button)
- **Software** is Part 1–5 (Hero + picture → Web apps → Mobile apps → Process → Bottom button)
- Contact form inbox + Resend key: **Settings** (Admin only)
- Your own password: **Account**

## Rules

- No HTML / layout / font changes in admin — ask the developer for those  
- One section = one job; don’t paste a whole page into one field  
- Keep the admin URL private  

## If something looks wrong

- Preview before publish  
- Revert if needed  
- Check you’re editing the right page  
- Still stuck → developer + Activity log (`/owadmin/activity`)
